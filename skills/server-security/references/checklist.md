# 提交前安全自检清单（全文）

> 由 `server-security` skill 的 §18 引用。提交前 MUST 逐条勾选；不适用项写明理由。

**认证与授权**
- [ ] 新接口需要认证？公开接口是否有明确理由？
- [ ] 每个按 ID 访问的资源都做了对象级授权（owner/租户/ACL）？
- [ ] 没有从请求参数中信任 `user_id / tenant_id / role`？
- [ ] 请求模型使用白名单字段，无 Mass Assignment？

**输入与输出**
- [ ] 入参有类型/长度/范围/枚举校验，拒绝未知字段？
- [ ] 无 SQL/命令/模板/路径拼接？
- [ ] 响应使用显式 schema，不含敏感/内部字段？
- [ ] 分页与批量有上限？

**文件**
- [ ] 上传：大小/数量/类型（扩展名+MIME+魔数）校验，存储名由服务端生成？
- [ ] 上传文件不在 Web 根/静态目录，存储为私有？
- [ ] 下载走鉴权接口或短时效签名 URL，不存在匿名直链？
- [ ] 响应头：`nosniff`、`Content-Disposition`、`Cache-Control`、受控 `Content-Type`？
- [ ] 文件名已净化，路径经规范化校验？
- [ ] 压缩包有 Zip Slip / 压缩炸弹防护？
- [ ] 导出文件按用户数据权限过滤，防 CSV 公式注入？

**配置与密钥**
- [ ] 无硬编码密钥/凭证，配置缺失时启动失败？
- [ ] 生产环境关闭 debug/文档/测试接口？
- [ ] CORS/CSRF/安全响应头配置合理？

**审计与运维**
- [ ] 敏感操作（登录、授权变更、上传、下载、导出、删除、管理操作）有结构化审计日志？
- [ ] 日志无敏感信息（密码/Token/完整证件号/签名 URL）？
- [ ] 高成本/高风险接口有限流与告警？
- [ ] 依赖已锁定并通过漏洞扫描？

**测试**
- [ ] 有越权、未认证、恶意文件、过期签名等安全用例？

## 本次补充（v2 新增）

- [ ] 限流与审计用的 IP 是否来自受控代理链，而非直接读 `X-Forwarded-For`？
- [ ] 授权缓存的键是否含 `user_id` / `tenant_id`？权限变更后是否失效？
- [ ] 重置 token 是否 CSPRNG 生成、单次有效、≤15 分钟？改密后是否吊销全部会话与 refresh token？
- [ ] Token / 验证码 / 签名比对是否使用恒定时间比较？
- [ ] 不可信文件（图片、Office、PDF、压缩包）是否在隔离进程或容器内解析？
- [ ] 分享链接是否可撤销、可过期、可审计？预签名 URL 是否 ≤15 分钟且未被日志明文记录？
- [ ] 限流是否返回 429 + `Retry-After`？并发修改是否有乐观锁或事务？
- [ ] 是否产出 SBOM，容器镜像是否签名并在部署时校验？私有包是否锁定 scope 与 registry？
- [ ] 审计日志是否有防篡改手段（哈希链 / WORM），且保留期限有合规依据？
- [ ] 项目含 AI 时：prompt 注入、模型输出校验、工具最小权限、成本限流、PII 边界是否覆盖？
